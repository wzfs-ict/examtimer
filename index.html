Quick Guide

  • Type Exam name and Duration (e.g., 45:00 or 01:30:00). Optional: set a Start time (uses today's date).
  • Click Add Timer. Then press Start when you’re ready. Use Start All for the whole hall.
  • Stop pauses a timer. Reset returns it to the original duration. When time ends, “TIME UP!” flashes.
  • Use Fullscreen for projection. You can safely navigate away and come back—the timers keep correct time.
  • Tips: Keep this page open during the exam. No internet required once loaded. For a dark room, press F11 to fullscreen the browser. Any other relevant information - centre number, school name, name of the exam/test and timer is very important and dynamically scales.
